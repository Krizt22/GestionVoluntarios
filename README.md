# GestionVoluntarios

Para correr el backend de forma local se debe ejecutar desde el CMD justo en la capreta "backend" del proyecto, el comando "npm install" (en caso que no exista la carpeta node_modules) y luego el comando "npm run dev". (Node.js debe estar instalado en el dispositivo además de estar activo un servidor web local cómo por ejemplo; Apache. Y además tener funcionando la base de datos en phpmyadmin)
